# buro.family

Статический сайт приложения «Бюро»: главная страница и юридические документы.

Не редактируйте файлы здесь вручную. Источник — основной проект «Бюро»:
тексты в `publishing/legal/*.md`, реквизиты в `publishing/details.json`,
сборка — `python3 scripts/build_site.py`, затем содержимое `site/` копируется сюда.

Хостинг: Timeweb Cloud Apps (статическое приложение, Москва), проект «Бюро».
